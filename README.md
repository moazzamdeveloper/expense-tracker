# 💰 Expense Tracker

A clean **Expense Tracker** to manage income and expenses with localStorage persistence.

## Features
- Add income and expense transactions
- Real-time balance calculation
- Transaction history list
- Delete transactions
- Data saved in `localStorage`

## How to Run
Open `index.html` in your browser.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
